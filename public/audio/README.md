# Audio

The heartbeat is synthesized in the browser (no file needed).

Optional music: put a track you own the rights to at `public/audio/music.mp3`.
It starts with a slow fade after her first touch of the heart. If the file is
missing, the experience simply runs with the heartbeat only.

Do not ship a commercial song (e.g. Ghostly Kisses) without a license; use a
licensed or royalty-free track with the same mood.
